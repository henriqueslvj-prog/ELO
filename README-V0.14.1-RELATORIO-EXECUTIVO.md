# ELO V0.14.1 — Relatório Executivo

## O que mudou
- O relatório ganhou uma capa institucional com a logo ELO já existente no projeto.
- Período analisado, quantidade de observações e data de emissão ficam destacados.
- Conteúdo organizado em resumo executivo, indicadores de registros, destaques, pontos de atenção, análise por categoria e próximos passos.
- Rodapé institucional e estilo responsivo para telas menores.
- Impressão otimizada para papel A4 e opção do navegador para salvar como PDF.
- O conteúdo continua sendo gerado a partir das observações do período; nenhum dado fictício foi adicionado.

## Arquivos alterados
- `src/main.jsx`: estrutura do documento de relatório.
- `src/styles.css`: estilo de tela, responsivo e impressão.

## Aplicação
1. Substitua os arquivos do projeto pelos desta versão.
2. Não é necessário executar SQL nem alterar as Edge Functions para esta atualização visual.
3. Publique o frontend na Vercel.
4. Gere ou abra um relatório existente, clique em **Imprimir / PDF** e escolha **Salvar como PDF**.

## Observação
Esta versão foi preparada sobre o ZIP ELO V0.14.0 fornecido. Teste na plataforma publicada antes de considerar a implantação concluída.
